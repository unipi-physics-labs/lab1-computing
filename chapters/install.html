1  Cominciamo?

Data di Pubblicazione

21 agosto 2026

Che cosa serve per cominciare? Buona domanda. Avrete bisogno essenzialmente di tre cose:

  1. un calcolatore;
  2. una istallazione funzionante di Python (e di parte dell’ecosistema scientifico associato);
  3. un editor di testo.

Se non siete sicure di avere tutto, non preoccupatevi: questo primo capitolo è pensato proprio per portarvi per mano all’esecuzione del vostro primo, glorioso programma di laboratorio. (Spoiler alert: faremo un grafico di dispersione.)

1.1 Il calcolatore

Prima che ve lo chiediate, possiamo riassumere i nostri requisiti come: va bene letteralmente qualsiasi cosa purché abbia una tastiera.

Avviso

Se volete (o avete necessità di) utilizzare un tablet per il corso di laboratorio, qui non troverete istruzioni utili, almeno per il momento. (Ma se riuscite ad identificare un setup funzionante e riproducibile potreste rendere il mondo un posto migliore contribuendo voi stesse a queste note.)

Da un punto di vista hardware non abbiamo grosse pretese. Se avete un calcolatore che vi permette di navigare su web e guardare film in streaming andrà benissimo anche per il corso di laboratorio.

Anche per quel che riguarda il sistema operativo va bene più o meno tutto. Gli strumenti che utilizzeremo sono tutti intrinsecamente multi-piattaforma e, a meno che non usiate un sistema particolarmente esotico è improbabile che non interagisca bene con il laboratorio di Fisica. In particolare non dovreste avere particolari problemi (ma, come sempre in questi casi il condizionale è d’obbligo) se utilizzare Windows, Mac-OS, o GNU/Linux.

1.2 Il linguaggio di programmazione: Python

Il linguaggio di programmazione che abbiamo scelto per il corso si chiama Python. Non perché sia, in assoluto, il migliore linguaggio del mondo (qualsiasi cosa questo voglia dire), ma perché ha molte caratteristiche che lo rendono adatto ai nostri scopi: è software libero, la sua sintassi è progettata esplicitamente per la massima espressività e facilità d’uso, ha una vasta libreria standard ed un enorme ecosistema associato di estensioni attivamente sviluppate, ed è uno dei linguaggi più utilizzati per il calcolo scientifico.

La pagina principale di Python è il punto di ingresso fondamentale per tutte le questioni legate al linguaggio, comprese l’installazione e la documentazione. Se non avete particolari esigenze (o, come più probabile, non sapete cosa vuol dire avere particolari esigenze) potete prendere l’ultima versione stabile (e.g., 3.14.6 a luglio 2026). Il tab Downloads in alto nella pagina web dovrebbe indirizzarvi di default all’ultima versione stabile per il vostro sistema operativo.

1.3 Tre modi di utilizzare Python

Se digitate python nel vostro terminale, e assumendo che tutto sia istallato correttamente, vi trovate immediatamente catapultati nell’interprete, e dovreste vedere qualcosa di vagamente rassomigliante a

lbaldini@nblbaldini:~$ python
Python 3.13.13 (main, Apr  8 2026, 00:00:00) [GCC 15.2.1 20260123 (Red Hat 15.2.1-7)] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>>

I tre simboli >>> nell’ultima riga stanno ad indicare che l’interprete è pronto ad accettare comandi: potete cominciare a scrivere, e l’interprete vi risponderà con il valore dell’ultima espressione ogni volta che premete invio, in quello che in gergo tecnico prende il nome di REPL (Read-Eval-Print Loop). Questo modo di utilizzare l’interprete si dice interattivo; è utile se volte usare Python come una sorta di calcolatore tascabile, se volete provare velocemente un costrutto o, più in generale, se quello che dovete fare è molto semplice.

>>> 3 + 17
20
>>>

Non passerà molto tempo prima che vi rendiate conto che l’uso interattivo di Python è molto limitante. Quando uscite dall’interprete ripetere una serie di operazioni una seconda volta richiede banalmente di dover digitare tutto da capo, che diventa estremamente tedioso molto velocemente. Per tutti i task di complessità non nulla è molto più conveniente scrivere tutti i comandi, uno dopo l’altro, in un file di testo (convenzionalmente con estensione .py), ed invocare l’interprete passando il percorso al file come argomento. Questo richiede un minimo di padronanza della shell e del filesystem, ma dopo il primo successo avete ufficialmente aggiunto un nuovo strumento (ed uno molto potente) alla vostra scatola degli attrezzi: avete appena scritto il vostro primo programma.

Consiglio

Può darsi che nel capoverso precedente si siano alcune parole (e.g., percorso, filesystem, file di testo) di cui ignorate il significato. Nel parleremo più diffusamente nel Capitolo 8, e potete fare un veloce salto in avanti se ne avete bisogno. Ma non lasciatevi tentare dall’utilizzare Python in modo interattivo nemmeno se incontrate qualche problema a questo stadio, perché vi assicuro che non è quello il modo in cui volete lavorare. Chiedete aiuto immediatamente se ne avete bisogno!

Esistono infine sul mercato vari Intregrated Development Environment (IDE) che uniscono in un’unica interfaccia grafica l’editor di testo, l’interprete Python e tutta una serie di altre cose (e.g., un browser del filesystem), e che sono la scelta tipica per chi programma professionalmente. (O almeno lo erano fino all’avvento degli agenti AI.)
